# Tarea 03: layout HTML/CSS
Estado: implementado experimentalmente.
Se compiló y enlazó litehtml BSD con un adaptador de texto TrueType/colores/bordes/gradientes, y se generó AVI desde el HTML. La evaluación del usuario rechazó la fidelidad de este compositor, por lo que se implementó el tema browser basado en Chromium/CDP para CSS y GSAP reales.
Limitación: litehtml no sustituye a un navegador, no interpreta JS, faltan algunas propiedades y bordes complejos. Se conserva como alternativa sin navegador.
